# quilt-hp-python documentation

`quilt-hp-python` is an async Python client for Quilt mini-split HVAC systems, with:

- a high-level async API (`QuiltClient`)
- a CLI (`quilt ...`) built on Typer
- a Textual TUI for live monitoring and control
- gRPC transport and streaming support

Use this documentation to understand architecture, protocol behavior, generated protobuf artifacts, integration patterns, and contributor workflows.
